# Cathetan sumber lan notasi

The frozen English source remains byte-for-byte intact, and aligned translated files preserve its mathematical notation. The reader supplies the following explicit editorial clarifications. These concern source defects or scope, not claims established by the Javanese canon.

- OLP-0012, relations-as-sets.tex: the example writes K = L union I and H = G union I without first naming its identity relation I. Read I there as the diagonal identity relation on the natural numbers that the preceding paragraph describes.
- OLP-0018, trees.tex, definition of branches: the source writes z in X minus B, although the tree carrier is A and X is not bound. Read X as A in this definition. With that reading, maximality says that every point outside B is incomparable to at least one point in B.
- OLP-0016 and OLP-0019 use R+ for different locally defined closures: reflexive closure in the orders section, transitive closure in the operations section. Preserve that local convention; do not substitute one meaning in the other section.
- OLP-0005 states uniqueness/existence informally under extensionality. OLP-0010 explicitly qualifies uniqueness by existence and rejects unrestricted comprehension. Read the chapter through that qualification.

- OLP-0021, function-basics.tex: the square-root example calls the selected root positive although its natural-number domain includes zero. At zero, read this as the nonnegative principal square root. The predecessor/successors example names its input n and subsequently writes x; read that x as the same input n.
- OLP-0024, inverses.tex: the proposition that every injection has a left inverse omits the empty-domain exception. Its proof chooses a in A. For nonempty A the proof works; for A and B both empty the empty function is its own inverse; for A empty and B nonempty the empty injection has no left inverse B to A. Read the proposition with A nonempty or B empty. The right-inverse proof explicitly states its use of the Axiom of Choice in a footnote, which is retained.

- OLP-0031, pairing.tex (continuing chapter, outside the first reader): the prose says the kth triangular number sums natural numbers strictly less than k, but gives k(k+1)/2. For the displayed sequence starting at zero and the correct pairing formula, read the sum through k, inclusive. The cofinite exercise omits the word subset before Nat in one sentence; its explicit Nat-minus-A definition supplies the correct meaning.
- OLP-0031's final inverse-enumeration exercise uses the broad injective definition of pairing. Such an inverse is defined on the range, not necessarily on every natural number. Qualify by surjectivity to Nat, or re-enumerate the range; for an empty product use the empty-set exception. OLP-0032 explicitly distinguishes non-surjective encodings and partial inverses. The countable-union exercise can require a countable-choice principle in general; do not silently treat it as a theorem of bare ZF.
- OLP-0032, pairing-alt.tex: the opening prose calls the second pair (0,2), while its own table correctly shows (0,1). A later sentence repeats (2,m) where the progression requires (3,m) next. Read those two prose occurrences accordingly. Original aligned mathematical strings are retained.
- OLP-0033, non-enumerability.tex: the introductory claim that every enumerable set admits a surjection from the positive integers requires a nonempty set, as OLP-0029's definition explicitly allows the empty set separately. The two sets proved non-enumerable here are nonempty; their diagonal proofs are unaffected. Apply the same qualification to the introduction's list/surjection discussion.
- OLP-0034, reduction.tex: the final illustrative formula displays a string of n zeroes, which is finite, while declaring a codomain of infinite binary sequences. As a nonsurjective counterexample into that codomain, use the constant all-zero infinite sequence for every input instead. The characteristic-sequence definition earlier names s_k without binding k; that subscript is just the name of the sequence determined by Z, not an additional parameter.
- OLP-0035, equinumerous-sets.tex: both empty-set cases mistakenly write g(x)=y when arguing from the bijection f from A to B. Read f(x)=y in those two parenthetical arguments. The defined enumeration g is not a function on A.
- OLP-0036, comparing-size.tex: in the detailed Cantor proof, the sentence claiming a result for each x in the diagonal subset must range over every x in A. The defining equivalence x in the diagonal subset iff x not in g(x) supplies both cases directly. The result covers empty A too, since the diagonal subset is then empty and no value of g exists. The preceding general equivalence between non-enumerability and Nat being strictly smaller assumes that every infinite set under consideration contains a countably infinite subset (available with Choice); it should not be inferred in bare ZF for arbitrary sets.
- OLP-0038, enumerability-alt.tex: the opening sentence has a grammatical omission (finite set is). Read it as saying that a finite set can be specified by enumerating its elements.
