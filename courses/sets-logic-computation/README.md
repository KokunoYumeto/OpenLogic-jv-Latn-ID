# Himpunan, Logika, Komputasi

Buku anggitané Richard Zach iki ngemot téori himpunan, logika urutan kapisan, bukti, lan komputasi. Tèks basa Jawa ditulis nganggo aksara Latin. Bab-bab buku iki migunakaké 176 pérangan saka *Open Logic Text*. Pambuka, ringkesan bab lan glosarium ana ing folder iki.

[Waca PDF](https://github.com/KokunoYumeto/OpenLogic-jv-Latn-ID/releases/download/slc-2026-11-16/slc-screen-jv.pdf) · [Tèks LaTeX](https://github.com/KokunoYumeto/OpenLogic-jv-Latn-ID/releases/download/slc-2026-11-16/slc-screen-jv.tex) · [Undhuh EPUB](https://github.com/KokunoYumeto/OpenLogic-jv-Latn-ID/releases/download/slc-2026-11-16/slc-screen-jv.epub) · [Waca HTML luring](https://github.com/KokunoYumeto/OpenLogic-jv-Latn-ID/releases/download/slc-2026-11-16/slc-screen-jv-html.zip) · [Sumber lan pandhuan mbangun](https://github.com/KokunoYumeto/OpenLogic-jv-Latn-ID/releases/download/slc-2026-11-16/slc-screen-jv-source.zip)

Buku anggitané Richard Zach lan para panulis Open Logic Project. Andharan logika tataran kapisan uga nganggo karya Jeremy Avigad. Ilustrasi potret déning Matthew Leadbeater. Terjemahan basa Jawa diprodhuksi AI OpenAI Codex. Pérangan Open Logic Project diterjemahaké nganggo GPT-5.6 Sol, GPT-6 Sol lan GPT-6.1 Sol. GPT-6.1 Sol nerjemahaké lan nyunting bahan kang mligi kanggo buku iki. Tata letak edhisi iki, koreksi notasi, katrangan diagram lan wacan rumus diprodhuksi nganggo GPT-6 Astra. Kabèh modhèl nganggo upaya nalar Ultra.

Tèks asli lan terjemahan nganggo lisènsi CC BY 4.0. Ilustrasi potret ing sampul lan pambuka pérangan anggitané Matthew Leadbeater nganggo CC BY-NC 4.0. Foto lan font manut lisènsi saben komponèn. Atribusi lan katemtuané ana ing buku lan arsip sumber.

Berkas `imports.lock` ngemot dhaptar pérangan sumber. Berkas `book.toml` nemtokaké buku asli lan pérangan basa Jawa. Berkas `slc-screen.tex` lan `slc.tex` minangka berkas utama kanggo nata buku. Pandhuan kanggo mbangun buku nganggo olpkit ana ing [pandhuan pangopènan](https://github.com/KokunoYumeto/OpenLogic-translations/blob/main/MAINTAINING.md).
