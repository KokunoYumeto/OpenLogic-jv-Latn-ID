# Himpunan, Logika, Komputasi

Buku anggitané Richard Zach iki ngemot téori himpunan, logika urutan kapisan, bukti, lan komputasi. Tèks basa Jawa ditulis nganggo aksara Latin. Bab-bab buku iki migunakaké 176 pérangan saka *Open Logic Text*. Pambuka, ringkesan bab lan glosarium ana ing folder iki.

Tèks asli anggitané Richard Zach lan para panulis Open Logic Project. Terjemahan sumber diprodhuksi AI OpenAI Codex, GPT-5.6 Sol lan GPT-6 Sol. Terjemahan lan panyuntingan buku diprodhuksi GPT-6.1 Sol. Tata letak kanggo piranti olpkit diprodhuksi GPT-6 Astra. Upaya nalar saben modhèl yaiku Ultra. Tèks buku nganggo lisènsi CC BY 4.0. Potrèt anggitané Matthew Leadbeater nganggo CC BY-NC 4.0. Foto lan aksara tetep manut lisènsi lan atribusi saben komponèn.

Berkas `imports.lock` ngemot dhaptar pérangan sumber. Berkas `book.toml` nemtokaké buku asli lan pérangan basa Jawa. Berkas `slc-screen.tex` lan `slc.tex` minangka berkas utama kanggo nata buku. Pandhuan kanggo mbangun buku nganggo olpkit ana ing [pandhuan pangopènan](https://github.com/KokunoYumeto/OpenLogic-translations/blob/main/MAINTAINING.md).
