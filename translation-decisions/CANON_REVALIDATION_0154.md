# Pamriksan Operator Utama Formula

Kabeh 19 blok Inggris lan Jawa OLP-0154 diwaca langsung, kalebu tabel lan OLPL-066 kang wis dibenerake sadurunge. Terjemahan, koreksi, panyuntingan lan pamriksan panulis AI kang padha nggunakake OpenAI Codex — GPT-6 Sol, Ultra effort; ora ana pamriksan manungsa kang diklaim. JV-P002 lan JV-P026 mung kanggo ragam akademik lan cara andharan; JV-P006 kanggo ejaan/serapan. Makna operator utama, kasus tag, occurrence tartamtu lan fungsi rekursif dikontrol sumber Inggris lan rumus. Tembung kemunculan lan mapanake ing prosa dibenerake dadi muncule lan nggayutake; ora ana definisi formal kang diganti. Suntingan pisanan dibalekake amarga QA ndeteksi urutan token malih; suntingan iki njaga urutan token sumber. Istilah khusus FOL tetep provisional.

## OLP-0154-P005

Judhul Operator Utama sawijining Formula njaga sesambungan operator karo formula, miturut token glossary kang wis ana.

Kanon kang diwaca: JV-P002, JV-P006. Rentang byte persis ana ing ledger pilihan.
