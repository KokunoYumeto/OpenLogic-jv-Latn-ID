\olpart{pl}{Logika Proposisional}

\begin{editorial}
  Bagean iki ngemot materi ngenani logika proposisional klasik. Bab
  kapisan mung cukup dhasar lan mung ndhaptar definisi lan asil;
  akeh bukti ora ditindakake, nanging ditinggalake minangka latihan.
  Materi ngenani sistem bukti lan teorema kelengkapan dijupuk saka
  bagean logika tataran kapisan, kanthi tag ``FOL'' disetel dadi salah.
  Mula kabeh kang gegayutan karo predikat, suku, lan kuantor ora
  dilebokake, lan pirembugan ngenani !!{structure}s~$\Struct{M}$ diganti
  dadi pirembugan ngenani !!{valuation}s~$\pAssign{v}$.

  Bagean iki dirancang bakal ditambahi kanthi jlentrehan kang luwih
  rinci, uga topik lan asil liyane, kayata kelengkapan fungsional
  kabeneran.
\end{editorial}
